## 修复「悬浮兼职卡片群」上传素材底色不透明

- 现象：用户上传的透明 PNG 贴纸/视频在组件里出现深色底座。
- 定位：渲染静帧 + Alpha 断言（`artifacts/gig-alpha/render.mjs`）确认两处原因：
  1. 纯素材模式卡片根节点带 `boxShadow`（默认开启）→ 深色圆角矩形底座（alpha 最高 67/255）；
  2. 视频走 `OffthreadVideo` 未开 `transparent` → 带 Alpha 的 WebM 渲染成整块不透明矩形。
- 改动：
  - `effects/BrollGigCardFloat.tsx`：抽出 `MEDIA_STYLE`（媒体层强制透明底色）；阴影只在招聘卡片模式生效（`CARD_SHADOW`）；
    视频统一 `transparent`；招聘卡片模式也支持视频素材；无素材时的占位块由深色实心改为虚线描边；
    招聘卡片缩略图有素材时不再铺紫色渐变；描述改为「纯素材模式保持纯透明底色」。
  - `effects/GigCardsEditor.tsx`：外观页阴影开关只在招聘卡片模式显示，纯素材模式给出纯透明说明。
- 验证：`node artifacts/gig-alpha/render.mjs` 全绿（图片/视频/阴影开关/卡片模式/探针对照）；
  `npm.cmd run build` 通过；`http://127.0.0.1:41735/` 200 且 Vite 能转换该组件。
- 沉淀：技能 `.agents/skills/effect-still-alpha-qa/SKILL.md`（静帧 + PNG Alpha 断言流程与坑）。

## 复查导出成片仍残留底色（链路级）

- 用户反馈「导出的成片/元素层里还有矩形色块底」。逐帧分析用户 16:05 的导出
  （`Downloads/悬浮兼职卡片群-透明导出-20260922-160527.mov`，ProRes 4444）：
  - 第 60/90 帧 alpha 分布 `a0 82.4万 / 1-8 32.1万 / 9-40 28.7万 / 41-120 15.9万 / 121-249 2.4万`，
    **单调衰减** → 判定是**卡片 boxShadow**（改动前纯素材模式误画阴影），不是遮罩平台值（遮罩会是整片 alpha≈82）。
  - 结论：残留来自**改动前**的导出，组件修复本身正确。
- 用户 16:34 的重新导出**失败**：`Error loading image with src: http://localhost:3000/api/media/temp/...`。
  导出无头浏览器访问不到 Remotion 默认的 3000/3001 端口，而 `local-vite.config.ts` 只迁移了 3001。
- 改动 `local-vite.config.ts`：
  - 新增 `normalizeLocalMediaUrl` / `normalizeLocalMediaUrlsDeep`（模块级）：
    把 `localhost|127.0.0.1:(3000|3001|41735)` 与 `/api/...` 相对路径统一改写到 `http://127.0.0.1:41735`，
    并递归覆盖 `cardsJson` 这类「JSON 存在字符串里」的字段（`JSON.parse` → 深扫 → 重新序列化）。
  - `/api/render` 里原有 `resolveLocalAssetUrl` 改为调用该 helper，`resolvedInputProps` 整体过一遍深扫。
- 验证：`artifacts/gig-alpha/e2e-export-check.mjs` 端到端通过 —— payload 里故意塞
  `http://localhost:3000/api/media/temp/...` 且卡片 `shadow: true`，真实 POST `/api/render` 后任务
  completed，产物 .mov 抽帧 alpha 直方图 `zero 201.4万 / mid 0.84万 / opaque 5.07万`，
  卡片盒外**零**非透明像素（改动前同位置有 79 万 mid-alpha）。
- 顺手发现（未改，仅记录）：`CardMaskLayer` 的 `normalizeCardMask(undefined).enabled === true`
  + `strength 0.32`，任何**不带 `cardMask` 字段**的 instance payload 都会被画一层全画布
  `rgba(0,0,0,0.32)`。工作台内实例都由 `createInstance` 带 `DEFAULT_CARD_MASK_NEW`（关闭），
  但外部/历史/编排 payload 要显式写 `cardMask: { enabled: false }`。
- 新增/重构回归工具：`png-alpha.mjs`（共用解码与统计）、`export-frame-probe.mjs`（入口级隔离）、
  `e2e-export-check.mjs`（链路级）；`render.mjs` 改为复用 `png-alpha.mjs`。
