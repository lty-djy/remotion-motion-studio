# 参考方向：横屏口播信息叙事

来源：用户提供的柱子哥 TzFilm《国内的数据标注时薪有300-3000？》《跑分猛如虎，实测二百五？揭秘Ai模型降智》，2026-09-13 曾抽查全片与开头半秒序列。若追求具体镜头还原，重新读取原视频，不凭本文件声明逐帧一致。

默认方向：暗色口播底片；左侧小标题、细线、短标签与逐项信息；右侧截图、录屏或可解释的示意图；章节中穿插微缩模型风格 B-roll。人物保持主要地位；素材出场由讲述驱动，论点结束再清场，允许留白。

- 层级：小号章节标识 → 一个主要数字/概念 → 少量补充条目。避免满屏大白色卡片、整句字幕复述、无意义装饰线与过多微小字。
- 金色用于价格/成绩等强调，蓝色适合信息结构，红色适合风险/疑问。具体配色服从最新参考，不能将一次金色样段当所有题材固定皮肤。
- 连续性：先出现主信息，再推进条目、标签、圈注或状态；超过一个论点时考虑换镜头。不要只有入场、静止、出场。
- 运动：克制的小幅滑入、透明度、划线、局部强调；给阅读留下驻留时间。动作出现对齐对应词的起点，而非任意固定间隔。
- 材料：真实截图强调出处；复杂微缩场景需要图像/视频资产。矢量结构图可以表达关系，但不能声称等同摄影级 B-roll。
