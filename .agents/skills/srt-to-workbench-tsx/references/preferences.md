## 工程经验（非审美认可）

- 当前 TSX 导入安全白名单以 `local-vite.config.ts` 为准；曾仅允许 react/remotion。不能将工作台内部相对 import 直接放进单文件交付。
- 2026-09-13 耳钉样段：安全校验、真实协议解析、独立 Player 关键帧和构建通过；未向用户当前会话导入。不能扩大为真实视频避挡或全片验证。
- Vite 的 TSX 模块地址可能返回转译 JS。下载源代码使用读取原文后生成 Blob，或交付真实磁盘文件；检查交付副本内容一致。
- Windows Node 文件 URL 转路径用 fileURLToPath，不能直接使用带百分号编码的 URL.pathname。
- 2026-10-03 完整版源码审阅：部分次级文字、数字、步骤及切换时刻硬编码，多个组件不等于所有内容均可独立修改；未来生成检查次级参数和实际 bounds，不把旧源码当作已验证的完整可编辑模板。
