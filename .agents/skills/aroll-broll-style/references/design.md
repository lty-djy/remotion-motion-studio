## 三个构图状态

依次查看：[口播与卡片共存](01-aroll-card.png)、[展开后的图解](02-broll-expanded.png)、[返回真人](03-aroll-return.png)。三帧来自样段内 0.9s、5.0s、6.7s，已经包含当期人物与字幕，仅作视觉参考，不作为下一期素材。

| 状态 | 构图 | 下一动作 |
| --- | --- | --- |
| A-roll + 卡片 | 上方真人圆角窗口，下方小型暗色卡片；保留字幕区域 | 同一信息面板向上扩展，主体图放大 |
| B-roll | 面板占据主画面，顶部小眉题/标题，中部主体图，下部重点数字和实体标签，底部细线注释 | 数字、标签分次揭示后驻留 |
| 回到 A-roll | 信息图退出，真人恢复画面；原音频不中断 | 按下一个论点决定是否再次出现信息层 |

连续性来自同一物件：面板轮廓、标题、插图、强调色应能在展开前后被认出。不要为每一张 B-roll 另造无关联的模板。

## 色彩与层级

| 用途 | 基准 | 使用方式 |
| --- | --- | --- |
| 舞台暗底 | 接近黑的冷灰 | 衬托真人窗口和卡片，透明导出时由合成场景提供 |
| 面板 | `#191F22` | 大面积暗石墨；避免过多装饰纹理 |
| 线框 | `#596063` | 细、低对比，用于外框；分隔线更暗 |
| 主文字 | `#F2F0E9` | 暖白；标题清晰，不堆多种字体 |
| 次文字 | `#BCC4C3` / `#A6B0B0` | 眉题、短注释、章节号 |
| 强调色 | `#DC796B` | 少量珊瑚色点、数字或左侧短线，避免全屏红色 |
| 实体标签 | `#E8E3D3` + `#222A2C` | 米白纸签、深色字，轻微倾斜/投影；按语义选择，不强制每段挂纸签 |

字体参考 Microsoft YaHei / 可用中文无衬线字体。1080 宽画面基准：眉题约 25px、标题 48px/700、脚注 24px、标签主字 78px/800、主数字可达 134px/700。文字长度变化时重新换行和缩放；540 编码预览中显示尺寸约减半。

面板约占画面宽度 91%，左右边距 48px，圆角 28px、描边 2px；内边距约 50px。标题在上方，不与主插图争中心。章节号和注释放在卡片底部的细分隔线两端。主体图有清晰轮廓、有限渐变/材质、柔和落地阴影；耳钉的金属切面只是本期示例，新题材使用相应示意图、真实截图或有效素材。

## 展开节奏的真实示例

样段取原视频 00:08–00:15，表中秒数从样段起点计，不是源视频绝对秒数。

| 动作 | 样段位置 | 说明 |
| --- | --- | --- |
| 面板进入 | 0.12s，约 0.35s | 先可见，再让观众辨认对象 |
| 面板展开 | 1.733s，约 0.40s | y 从 925 到 60，高从 590 到 1515，宽保持 984；插图由小到大 |
| 数字卡出现 | 2.683s，约 0.30s | 向上小幅位移 + 透明度，强调说到的数字 |
| 实体标签出现 | 4.05s，约 0.34s | 小幅滑入、轻微旋转与缩放，保留停留时间 |
| 返回真人 | 6.133s，约 0.27s | 信息层退出，人物恢复；实际衔接同时控制人物窗口 |

可用 `p = clamp((t-at)/span, 0, 1)` 和 `p*p*(3-2*p)` 进行平滑插值。少量位移、透明度、尺寸变化优先；不默认加持续漂浮、剧烈弹簧或旋转特效。新内容由 SRT 和阅读时长确定时序，不能直接套用本表。

## 参数与编辑设计

- 场景锚点：图解进入、展开开始、展开时长、返回时间、返回时长。若当前协议无法跨实例共享参数，明确各层的同步方式，检查用户调整后不会漂移。
- 面板层：颜色、圆角、描边、边距、展开幅度；与人物构图分开。
- 内容层：标题/眉题/数字/标签文案、各层颜色、位置、大小、出现时间和退场时间；尽量让常用调整在工作台属性与时间线上完成。
- 示例耳钉不复用到其他主题；图形结构随主题重做。源码备份仅用于识别风格，不能直接重新导入已删除的三组件包。
- 用户给了新参考时新参考优先；横屏可改为人物与信息卡左右共存，但仍保持同一面板展开、同一物件和视觉语言。不同章节允许有不同风格。
